# Official MEP affiliations

A hosted update also reads the official roster for the latest term it is checking. It adds new official profiles and checks up to 25 overdue membership records per release. The runner records skipped or failed details. A source error leaves existing membership records available.

Newly imported contributions and recent unresolved contributions can be linked when the name is unique in the official roster and its verified membership covers the speech date. Existing historical identifiers and attributed speech groups stay intact. The archive retains dated mandate and political group revisions separately from the affiliation attributed to an individual speech. The speaker profile and `/api/speakers/{id}/affiliations` show verified membership dates when available. Identity conflicts are recorded and kept unresolved. The public data contains no contact fields from the Parliament detail endpoint. Older terms can be synchronized in bounded batches with the same adapter when rehearsing the historical archive.

[European Parliament Open Data API](https://data.europarl.europa.eu/en/developer-corner/opendata-api)
